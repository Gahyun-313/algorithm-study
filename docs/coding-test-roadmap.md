# Python 코딩테스트 종합 로드맵

## .py와 Jupyter Notebook 기준

코딩테스트 준비는 `.py` 파일 중심이 일반적이다.

- 실제 제출 환경은 대부분 Python 코드 한 파일을 제출하는 방식이다.
- GitHub에 풀이를 쌓을 때도 `.py` 파일이 리뷰와 기록에 유리하다.
- Jupyter Notebook은 알고리즘 개념 실험, 표/그림 정리, 복잡도 비교 메모용으로만 사용한다.

### 2순위: 지원 기업 전체 커버용

- 투 포인터 / 슬라이딩 윈도우

### 3순위: 시간 남으면 확장

- 다익스트라
- 유니온 파인드
- 트리
