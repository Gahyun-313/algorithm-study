# 코테 복기 노트 도우미 — 진행 방식

작성일: 2026-09-22

## 배경
- 코딩테스트 준비가 처음이고, 시간복잡도/자료구조(해시, 셋 등)를 아직 배우는 중
- 언어: Python 3 (`sys.stdin.readline` 입력), 에디터: VS Code (Windows)
- 복기 노트는 별도 md가 아니라 **풀이 코드 파일 하단의 파이썬 주석**으로 남김

## Claude가 하는 일
문제(내용 또는 링크)와 내 풀이 코드를 보내면, 아래 4칸만 채워서 준다.
나머지 칸(문제, 처음 생각, 막힌 점, 다음에 조심, 다시 풀 날짜)은 내가 직접 쓴다.

1. `[유형]` : 구현 / 정렬 / 그리디 / 브루트포스 / 스택·큐 / 해시 / 이분탐색 / 투 포인터 / DFS·BFS / DP 등 고정 목록에서 선택 (표기가 흔들리지 않게)
2. `[자료구조/알고리즘]` : 풀이에서 실제로 쓴 것. 처음 나오는 개념이면 짧은 뜻 병기 (예: `set (중복 제거, 조회 O(1))`)
3. `[시간복잡도]` : **내가 쓴 코드 기준**으로 계산 + 근거 한 줄 (예: `O(N) (for문 1개)`)
4. `[핵심]` : 이 문제에서 기억할 포인트 1~2줄

출력은 그대로 복붙 가능한 `'''` 주석 블록의 해당 줄만 준다.

## 추가 피드백 규칙
노트 칸과 별도로 한두 줄 덧붙인다.
- 풀이가 문제의 N 범위에서 시간 초과 위험이 있을 때
- 더 나은 풀이/자료구조가 있을 때
- 예: "이 풀이는 O(N²)라 N이 10만이면 위험해요. set을 쓰면 O(N)으로 줄일 수 있어요."
- 문제가 없으면 굳이 덧붙이지 않는다.

## 시간복잡도 판단 기준
- for문 1개 → O(N), 중첩 for문 → O(N²)
- 파이썬은 대략 1초에 1천만~5천만 연산 기준으로 N 범위와 비교
- N ≤ 10만이면 O(N) 또는 O(N log N)이어야 안전

## 노트 양식 (풀이 파일 하단에 붙임)
```python
'''
[문제] 플랫폼 번호 문제명 / 링크
[유형] 
[자료구조/알고리즘] 
[시간복잡도] O( )
[처음 생각] 
[막힌 점/틀린 이유] 
[핵심] 
[다음에 조심] 
[다시 풀 날짜] 
'''
```
- 맞힌 문제는 `[핵심]`까지만 써도 됨.
- `[처음 생각]`, `[막힌 점/틀린 이유]`, `[다시 풀 날짜]`는 틀렸거나 오래 걸린 문제에만 쓴다.
- 유형별 복습: VS Code에서 `Ctrl+Shift+F`로 `[유형] DP`처럼 검색

## 작성 예시 (백준 10871 X보다 작은 수)
```python
'''
[문제] 백준 10871 X보다 작은 수 / https://www.acmicpc.net/problem/10871
[유형] 구현 (배열 순회)
[자료구조/알고리즘] 리스트, 완전탐색
[시간복잡도] O(N)  (리스트를 한 번만 훑음)
[처음 생각] 
[막힌 점/틀린 이유] 
[핵심] 조건(a[i] < x)에 맞는 값만 출력, 순서 유지
[다음에 조심] 출력 시 end=" " 로 한 줄에 출력
[다시 풀 날짜] 
'''
```

## 새 세션에서 시작할 때
1. 이 문서와 프로젝트의 `claude/session-context.md`를 읽는다.
2. 문제 + 풀이를 받으면 위 규칙대로 4칸 + 필요 시 피드백 한두 줄로 응답한다.
3. 별도 확인 질문 없이 바로 진행한다. (이미 합의된 방식)
